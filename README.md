## 🚀 Como Rodar o Jogo no Seu Computador (Sem Sofrer com NPM!)

Esse jogo foi feito artesanalmente com **HTML5 Canvas puro, Vanilla JavaScript ES6 e Web Audio API**. Nada de baixar metade da internet dentro de uma pasta `node_modules`.

### Opção 1: Via Python (O jeito mais rápido)
Se você tem Python 3 instalado no seu PC/Mac/Linux:

```bash
# Clone o repositório
git clone https://github.com/reimon/protocolo-primeira-vaga.git

# Entre na pasta
cd protocolo-primeira-vaga

# Inicie o servidor embutido do Python
python3 -m http.server 8080
```
Abra no seu navegador favorito: **`http://localhost:8080`** e bom jogo!

### Opção 2: Via Extensão Live Server (VS Code)
1. Abra a pasta do projeto no **VS Code**.
2. Clique com botão direito no arquivo `index.html`.
3. Selecione **"Open with Live Server"**.

### Opção 3: Via Node.js (se você for teimoso)
```bash
npx serve -p 8080
```

## 🏗️ Engenharia por Trás do Jogo (Para Alunos Curiosos)

Para quem quiser abrir o código e aprender como tudo foi construído:
- `src/world/ParallaxBackground.js`: Sistema de parallax em múltiplas camadas com calçadão e mar animado em tempo real.
- `src/world/LoadingScene.js`: Tela de abertura épica com runas flutuantes e compilação de requisitos tech.
- `src/assets/PixelRenderer.js`: Pipeline híbrido de renderização de sprites Hi-Bit em 16-bit com carregamento via `Promise.all`.
- `src/audio/SoundEngine.js`: Sintetizador chiptune completo usando pura matemática na Web Audio API (ondas quadradas, triângulo e ruído branco procedural). Zero arquivos MP3 pesados!
- `src/entities/`: Físicas com **Coyote Time** (tolerância de pulo) e **Jump Buffering** para que os controles pareçam tão responsivos quanto os de *Celeste* ou *Metal Slug*.
- `src/tests/SelfTest.js`: Suite com **26 testes unitários automatizados** rodando dentro do próprio browser/Node.
